# Post-shared-task analysis notebooks

These notebooks analyze the released ImageEval 2026 Task 1b English gold labels
against the ten prediction archives already stored in this repository. The analyses
are **retrospective**: they do not change the official leaderboard submission or its
reported rank.

## Notebooks

1. `01_paired_comparisons.ipynb`
   - exact two-sided paired McNemar tests;
   - Holm correction across all pairwise tests;
   - error intersection, union, and Jaccard similarity;
   - item-level error migration for prompting-versus-QLoRA and 2,348-versus-2,600.
2. `02_qlora_ensembles.ipynb`
   - every three-adapter majority vote;
   - a four-adapter vote with the devtest-selected 2,348 adapter as a declared tie-breaker;
   - the non-deployable oracle upper bound (any adapter correct);
   - adapter agreement and per-item error patterns.
3. `03_subgroup_position_analysis.ipynb`
   - Wilson 95% confidence intervals by country, category, and subcategory;
   - Wilson intervals by gold statement position;
   - position-specific 3-by-3 confusion matrix;
   - export of the 35 QLoRA-2,600 errors for qualitative analysis.
4. `04_error_taxonomy_iaa.ipynb`
   - blinded, independently editable sheets for two raters;
   - the fixed three-class taxonomy and optional item/image viewer;
   - raw agreement, Cohen's kappa, and a disagreement sheet.

## Running

From the repository root, install the small analysis dependency set and open Jupyter:

```bash
python -m pip install -r post_task_analysis/requirements.txt
jupyter lab
```

Run the notebooks in numeric order. On first use, notebook 1 downloads the public
`task1b/test_en.jsonl` file from
`QCRI/ImageEval-ArabicNLP26`. To use an existing copy instead:

```bash
set IMAGEEVAL_TEST_GOLD=C:\path\to\test_en.jsonl
```

On Linux/macOS, use `export IMAGEEVAL_TEST_GOLD=/path/to/test_en.jsonl`.

All notebooks validate that the gold set has 1,000 unique IDs, each submission has
the same IDs, and every item has exactly three Boolean predictions. Tables and plots
are written to `post_task_analysis/outputs/`.

## Independent second rating

Run notebook 4 once to create `annotations/rater1.csv` and `annotations/rater2.csv`.
Give each rater only their own sheet and the common rubric. Raters should fill only
the `label` and optional `notes` columns, without discussing cases or viewing the
other sheet. After both sheets are complete, rerun the final cell to calculate kappa
and export disagreements for adjudication. Do not change labels after seeing the
agreement result; record adjudicated labels separately if needed.

## Rebuilding

The notebooks are generated by `build_notebooks.py` so their shared loading and
validation code stays identical. After editing the builder, run:

```bash
python post_task_analysis/build_notebooks.py
```
